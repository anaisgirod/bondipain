🔍 SEO / Référencement

Ce que Google et les réseaux sociaux affichent pour votre site. Titre & description = essentiels pour le référencement.

Titre de la page (balise title) — ~60 caractères
Meta description — ~155 caractères (résumé affiché sous le titre dans Google)
Mots-clés (séparés par des virgules) — optionnel
Image de partage réseaux sociaux (URL) — s'affiche quand on partage le lien (WhatsApp, Facebook…)
